# Mozhi 0.3.1

A fix release for v3. Everything new in 0.3.0 still applies: [edit while you speak, emoji in the pill, errors that keep your words](https://github.com/justkamal07/mozhi/releases/tag/v0.3.0).

## Fixed

- **A phrase could go missing from a dictation.** If the pill was still loading when Mozhi committed your first phrase (most likely right after launch, or on a busy machine), that phrase could be dropped from what was inserted. Phrases are now numbered: the pill notices a gap and resyncs, and Mozhi never accepts a draft that skipped one.
- **"Mozhi quit unexpectedly" on quit.** whisper.cpp's Metal backend aborted while shutting down because the speech model was still loaded. The model is now released before Mozhi exits.

## For testers

`mozhi --selftest speech.wav --selftest-app com.apple.TextEdit` dictates a recording into the given app, and pastes only if that app really is in front (otherwise it copies), so an automated run never types into the wrong window.

## Install

**macOS** (Apple Silicon, macOS 12+): download [Mozhi-macOS-AppleSilicon.dmg](https://github.com/justkamal07/mozhi/releases/latest/download/Mozhi-macOS-AppleSilicon.dmg), open it and drag **Mozhi** to Applications. Mozhi isn't notarised by Apple yet: the first time, right-click it in Applications → **Open** → **Open**. Then allow **Microphone** and **Accessibility**. Updating from an earlier version? Remove the old Mozhi entry in System Settings → Privacy & Security → Accessibility and add the new app; macOS treats each unsigned build as a new app.

**Windows** (10/11, 64-bit): download [Mozhi-Windows-x64-setup.exe](https://github.com/justkamal07/mozhi/releases/latest/download/Mozhi-Windows-x64-setup.exe) (or the `.msi`) and run it. SmartScreen may say the app is unrecognised: **More info** → **Run anyway**. The Windows build hasn't been tested on a real PC yet; please [report anything odd](https://github.com/justkamal07/mozhi/issues/new/choose).

The first run downloads a speech model (about 265 MB for the recommended Tamil model). After that everything runs offline.
