# Mozhi 0.3.0 · மொழி v3

## Edit while you speak

Click into the text while Mozhi is still listening. Move between words, fix a name, add a line;
Mozhi keeps listening, and every phrase you say next goes in **where your cursor is**. The words it's
still hearing show on a live line underneath. ↵ inserts, ⇧↵ adds a line, esc cancels.

## Emoji, without leaving the pill

- A **😊 button** in the pill opens an emoji picker: an everyday row (🙏 😊 😂 ❤️ 👍 🔥 🎉 🪔 🍛 ☕),
  your recent picks, and every emoji by group.
- **Search in English, Tamil or Tanglish**: *heart*, *இதயம்*, *sirippu*, *sapadu*, *vanakkam*.
- **Say it**: *"heart emoji"*, *"thumbs up emoji"*, *"இதயம் எமோஜி"*, *"சிரிப்பு எமோஜி"*. Turn it off in
  Writing → Voice emoji.

## Errors that keep your words

- If a transcription fails, your recording is kept. **Try again** transcribes it once more and shows
  the result for you to check before it's inserted.
- Every error now offers the fix that matches it: microphone or Accessibility settings, Models,
  or **Copy text**.
- **Report** (in the pill and in About) opens a GitHub issue already filled in with your version,
  system, model, the error and recent log lines. Nothing you dictated is included, and nothing is
  sent until you submit it.
- Fixed: "failed to encode" errors when you finished speaking while a live-preview pass was still
  running on the GPU. Inference is now serialised and a failed final pass retries once.

## Under the hood

- Phrases are committed at natural pauses and transcribed at full quality, so long dictations
  stay accurate and the final pass after ⌃⌃ only has the last few words to do.
- `mozhi --selftest speech.wav` runs a complete dictation from recorded audio, for release checks.

## Install

**macOS** (Apple Silicon, macOS 12+): download [Mozhi-macOS-AppleSilicon.dmg](https://github.com/Kamal007OLica/mozhi/releases/latest/download/Mozhi-macOS-AppleSilicon.dmg), open it and drag **Mozhi** to Applications. Mozhi isn't notarised by Apple yet: the first time, right-click it in Applications → **Open** → **Open**. Then allow **Microphone** and **Accessibility**. Updating from an earlier version? Remove the old Mozhi entry in System Settings → Privacy & Security → Accessibility and add the new app; macOS treats each unsigned build as a new app.

**Windows** (10/11, 64-bit): download [Mozhi-Windows-x64-setup.exe](https://github.com/Kamal007OLica/mozhi/releases/latest/download/Mozhi-Windows-x64-setup.exe) (or the `.msi`) and run it. SmartScreen may say the app is unrecognised: **More info** → **Run anyway**. The Windows build hasn't been tested on a real PC yet; please [report anything odd](https://github.com/Kamal007OLica/mozhi/issues/new/choose).

The first run downloads a speech model (about 265 MB for the recommended Tamil model). After that everything runs offline.
